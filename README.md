# Online Examination System - SVV Project

## Project Overview
This project implements a complete Software Verification and Validation (SVV) pipeline for an Online Examination System.

## Project Phases
1. Requirement Engineering
2. Formal Modeling using Z Notation
3. Functional Specification using VDM-SL
4. Structural Verification using Alloy
5. Validation and Security Testing
